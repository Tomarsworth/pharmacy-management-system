# Pharmacy Management System

Консольное приложение для управления аптекой.

## Функциональность

* просмотр списка лекарств
* добавление новых лекарств
* удаление лекарств
* продажа (уменьшение количества)
* вход и выход пользователя
* роли: admin / cashier

## Структура проекта

Проект разделён на слои:

* ui — работа с пользователем
* service — бизнес-логика
* repository — работа с данными
* model — модели данных
* config — подключение к базе
* session — текущий пользователь

## Технологии

* Java
* Maven
* PostgreSQL
* JDBC

## Запуск

Собрать проект:

```bash
mvn clean package
```

Запустить:

```bash
java -jar target/*.jar
```

Перед запуском:

* запустить PostgreSQL
* создать таблицу medicines
* указать настройки подключения в DatabaseConfig

## Примечание

Источник данных можно заменить, не меняя бизнес-логику (через интерфейс repository).
