# 💊 Pharmacy Management Console App

## 📌 О проекте
Консольное Java-приложение для управления аптечным складом.
Позволяет добавлять, удалять, продавать лекарства и автоматически обновлять остатки.

Проект демонстрирует знание ООП, коллекций и работы с файлами.

---

## ⚙️ Функционал
- Просмотр списка лекарств
- Добавление лекарства
- Удаление лекарства
- Продажа лекарства
- Сохранение данных
- Загрузка данных при запуске

---

## 🧱 Архитектура
Main — запуск программы  
Service — бизнес-логика  
Model — структура данных  
Storage — работа с файлом

---

## 🚀 Запуск
Запустить класс Main
